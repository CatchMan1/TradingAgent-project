# 新闻情绪 + EODHD 增强实验

本归档包含 AAPL、AMZN 两组完整实验，每股 21 个决策日。信号日期为 **2026-07-31 至 2026-08-28**，对应收盘收益区间截止 **2026-08-31**。GOOGL 未运行此增强方案。

收益和回撤均以百分数表示。最大回撤列为正的损失幅度，越低越好。

相对原始 Multi Agent，AAPL 增加 **1.5914 个百分点**：持仓时点变化贡献 **1.0914**，减少换手费贡献 **0.5000**。AMZN 增加 **1.4957 个百分点**，两组换手相同，差额来自持仓时点变化。这是交易账本的精确算术分解，不是 EODHD 的因果归因。

## 实现方式

固定原技术、新闻、基本面报告及各日历史记忆。新闻情绪模块逐条判断相关性，给出 -2 至 +2 的序数评分、原文引用、理由和置信度；程序检查编号覆盖及引用原文。AAPL 复用已审核标签，AMZN 按同一实现补算。

EODHD 使用严格早于决策自然日的最近一日记录，提取原始分数、相邻自然日变化、相对此前二十个观测的 z-score、文章数量和时效限制。历史均值与标准差不含所选情绪记录本身或未来数据。

情绪分析师解释变化、证据充分性及与其他分析的一致性。随后运行原多空各一次讨论、研究经理、交易员、三类风险分析和投资组合经理。分数不直接映射买卖，不新增做空或比例仓位。

## 统一评价口径

使用信号日收盘至下一交易日收盘的简单收益。净值采用加法累计，初始净值 1、仓位 0。Buy/Overweight 映射 1，Sell/Underweight 映射 0，Hold 延续前一仓位。每单位换手费用 10bps，不额外期末平仓，现金利息为零。交易收益不扣 API 调用费。

买入持有从本窗口初始空仓买入，因此计入一次 10bps 入场费用；不能与从更早持有、窗口内没有入场费的月度表直接混用。

## 离线复现

在仓库根目录运行，无第三方依赖、无需凭据、不会产生模型费用：

```bash
python results/sentiment_eodhd/aug2026/replay.py
```

脚本从已归档收盘价和评级独立重建每日仓位、费用、净值、回撤与指标。

- `summary.json`：指标和收益分解。
- `AAPL/`、`AMZN/`：实际评级、逐日收盘价回放输入、全部收益与持仓账本。
- `protocol.json`、`provenance.json`：方法、局限及来源校验值。
- 仓库的 `data/decisions/sentiment_eodhd/news_plus_eodhd_aug.csv`：42 条实际信号，无虚构的期末决策。

公开包用于离线核验交易结果，不提供付费模型重生成入口。完整模型决策文本、逐条情绪分析、实现快照、API 原始响应、账户余额和凭据均未上传。

## 结论边界

两股样本中增强方案均提高收益并降低回撤，但本实验同时增加了外部数据与解释步骤。对照来自历史运行，模型调用时间和输出随机性不同，不能把改善全部归因于 EODHD。日期段此前已经探索过，不能视为独立样本外验证。

EODHD 官方文档描述汇总指标涉及新闻及社交媒体，但本接口没有提供逐来源拆分，不代表本项目直接取得了 Reddit 或 StockTwits 原帖。日度汇总的历史发布时间、时区、修订及 demo 与正式数据一致性尚未核实；滞后一天只是暂定处理。原历史报告也继承信息截止限制，不能宣称已证明无前视。

二元执行还会把“维持已有核心仓位”的叙述型 Hold 映射成保留当前模拟仓位；初始空仓时即继续空仓。报告中的条件加仓、止损和部分减仓不会被执行。

AMZN 四天的源引用修复仅恢复原文编码、标点和一位编号误写，未改相关性、评分、理由或置信度；原始严格校验保持启用。AAPL 有一次情绪解释超长后的格式重生成。修复次数见来源记录，原始内部文本保留在本地。
