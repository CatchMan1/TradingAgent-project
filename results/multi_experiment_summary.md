# 多实验回测结果：与同期基础多 Agent 策略比较

**AAPL 的比例仓位实验显著缩小了回撤；做空评级映射提高了 AAPL 和 AMZN 的全量净收益，但也加深了两者的回撤。** 全量样本中，没有变体同时提高净收益、缩小最大回撤并提高年化 Sharpe。剔除财报窗口后，AMZN 和 GOOGL 的做空评级映射在三项指标上均优于同期基础策略。

## 比较口径

比较对象是归档信号覆盖的六个非单 Agent 变体。每一行都取同一只股票、同一组交易区间的基础多 Agent 策略作为对照。日期为 2026 年的起止收盘日。信号日的目标仓位乘以下一收盘相对当日收盘的简单涨跌幅，再按每单位换手 0.1% 扣费。净收益按固定基数累加，做空结果未扣借券费用。此次比较沿用历史决策。

表中每格按 **基础策略 → 变体** 排列。净收益和最大回撤以百分比表示，回撤越接近零越浅。Sharpe 按 252 个交易日年化，短窗口中的估计对个别交易日较敏感。

## 哪些改动有用

**比例仓位主要改善风险控制。** AAPL 的 21 个区间里，比例仓位的平均股票权重仅为 3.6%，最高为 20%；同期基础策略平均为 28.6%。较低的敞口有助于解释回撤为什么从 2.29% 缩小到 0.36%，也解释了为何基础策略盈利时，该变体仍可能小幅亏损。筛选后它比基础策略少亏，但两个窗口的 Sharpe 都较低。该变体使用单独生成的权重，不能仅凭这一结果认定部分仓位提高了择时能力。

**做空评级映射的表现取决于股票和窗口。** AMZN 的评级映射在筛选后取得最明显的改善：净收益从 10.32% 升至 33.79%，回撤从 6.01% 缩小至 3.78%。放回四个区间，变体仍有收益优势，但最大回撤达到 18.05%。GOOGL 的三项指标也在筛选后改善，全量净收益却更低。AAPL 则在剔除窗口后失去原有的收益优势。三只股票都显示，评估做空映射时应同时报告财报窗口内外结果。

**其余变体的结果。** 新闻情绪在 AAPL 两个样本中的净收益都低于基础策略。做空审批虽然允许负仓位，但本次 21 个区间的实际仓位与基础策略逐期相同，没有出现负仓位，因此收益和风险指标一致。9 月 AAPL 三轮辩论的净收益为 1.20%，略低于单轮的 1.41%，且回撤更深；两者均落后于同期基础策略的 9.65%。

短窗口实验只覆盖一只股票。检验比例仓位本身的作用，可以固定同一批决策文本，仅改变评级到仓位的映射；检验做空策略，则需要在预先指定的多个财报窗口重复比较，并纳入借券成本。
