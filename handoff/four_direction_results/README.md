# 四个方向的实验结果包

解压后打开 `index.html` 浏览图表和文件，或用 `experiment_catalog.csv` 找实验。每个实验旁边有 EXPERIMENT.md 说明版本与局限。

## 内容

- 01_position：完整流程比例仓位的 AAPL 八月结果；exploratory 下保留早期三股票八/九月仓位实验、固定比例对照、缩短风险审核试验。
- 02_sentiment：恢复原提示词的 AAPL 八月情绪实验；早期有混杂因素的版本单列。
- 03_short：AAPL 八月显式做空审批，以及 AAPL/AMZN/GOOGL 七至九月、十月部分的减持直接做空映射；逐月与连续账户分别保留。
- 04_debate：AAPL 九月一轮/三轮重新运行的对照结果。

包含：CSV 逐日交易/仓位/指标，JSON 汇总与决策，PNG/PDF 图表，以及实际存在的实验协议。并非每组实验都有完全相同的字段；没有补造缺失结果。

## 使用和解释

1. 收益小数如 0.0281 表示 2.81%；具体列名以原 CSV/JSON 为准。最大回撤通常记录为负数。执行日与信号日不同，通常次日开盘成交，月底下一交易日开盘平仓。
2. 完整流程比例仓位只完成了 AAPL 八月，不把早期简化流程的其他股票数据冒充新框架结果。其后提示词曾修订，代码交接包不一定逐字匹配每个历史实验。
3. 情绪对照来自历史原版；不同批次模型调用存在随机性和运行条件差异。早期有混杂因素的实验只能用于研究过程记录。
4. 机械减持转做空仅是交易映射实验，不是新的模型做空决策；假定借券可用，年费3%，单边交易费0.1%，计入股息补偿，未模拟盘中强平、召回和滑点。十月只到10月9日开盘估值。
5. 独立月份账户重新从初始资金开始；连续账户不按月重置，不能直接相加月度收益。
6. 报告可能含历史 API 成本估算，单价对应当时条件；不代表当前报价或账户余额。本次只归档已有结果，API调用0次。
7. 无 .env、API密钥、余额查询记录、原始API响应或原始新闻快照。保留模型最终决策文本用于研究审阅，文本不是事实正确性保证。
8. `manifest.json` 记录原文件及导出文件哈希。JSON删除账户余额等字段，文本中的本机绝对路径被替换；交易指标不修改。

代码对应此前的 four_directions 源码交接包。本结果包是研究记录，不保证只靠这些结果文件即可重新生成所有模型报告。
