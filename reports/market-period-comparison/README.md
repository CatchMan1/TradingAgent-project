# 两个候选时期的市场状态核对

核对日期：2026-10-15。结论：2024年一季度与2026年7—8月的走势、个股风险和收益来源有明显描述性差异，不应视为相似市场环境，也不能据此推断尚未运行的Agent结果一定好或差。

## 数据与口径

三股行情来自团队data/prices/，逐文件SHA-256与data/sources.json一致；SPY（标普500 ETF）和QQQ（纳斯达克100 ETF）来自本次公开Yahoo chart API查询，原始响应保存在同目录。来源URL与文件哈希见provenance.json；计算见analyze.py，全部指标见period_metrics.csv。

使用每段前一交易日收盘至最后交易日收盘的含分红总收益，不扣交易费或API费用。2024-01-02至2024-03-28有61个交易日；2026-07-01至2026-08-31有43个交易日。波动率为每日简单总收益的总体标准差（ddof=0）乘sqrt(252)，回撤包含起始净值1。ETF代表指数暴露，但不是指数本身。

这些是市场诊断，不能当作正式策略收益；Agent回测采用下一开盘执行、开盘至下一开盘收益，边界和费用不同。所有行情均是事后取得的供应商版本，保留历史修订风险。

## 主要发现

- 大盘趋势变弱：SPY从2024Q1的+10.39%变为2026年7—8月的+2.72%，最大回撤从-1.71%扩大到-3.38%。两段SPY年化波动率约10.85%/11.03%，波动本身相近，但上涨趋势强度不同。
- 科技板块差异更大：QQQ从+8.56%变为-2.67%，年化波动率从15.68%升至20.95%，最大回撤从-3.23%扩大到-10.14%。
- AAPL方向反转：-10.82%对+9.60%；年化波动率20.84%对30.07%。2024Q1中AAPL偏弱，2026年候选期偏强。
- GOOGL完整窗口方向反转：+8.05%对-5.04%；年化波动率27.79%对37.11%。2024Q1本身也有先跌后涨，不能只用期末收益给每一天贴“牛市”标签。
- AMZN两段均上涨，但2026更颠簸：+18.72%对+8.99%；年化波动率26.46%对46.95%；最大回撤-4.85%对-11.10%。

完整窗口长度不同，不能把累计涨幅大小直接当作趋势强度的全部证据。补做等长度敏感性检查：2024年前43个交易日中，SPY为+7.78%、QQQ为+8.42%，仍强于2026的+2.72%/-2.67%；AAPL为-8.94%，仍与2026方向相反。GOOGL同期为-4.54%，说明其“方向反转”对2024窗口长度敏感。综合风险和路径可判断差异，但这些描述性统计不能证明分布在统计意义上不同。

## 对实验的影响

1. 不直接比较2024Agent收益与2026Agent收益来宣称算法改进。两段长度、行情和个股风险不同。
2. 每个时期内部，所有系统必须使用同一批股票、日期、证据与交易费用；比较多Agent减单Agent、相对各股Buy and Hold的收益差，以及最大回撤和API成本。跨时期只检查结论方向是否一致。
3. 2026环境可能使频繁交易更容易受震荡和费用影响，但实际是否发生必须由决策结果检验。长期只做多/空仓策略在市场走弱时也可能通过减少持仓降低损失，不能从市场下跌直接推导模型失败。
4. 2026开发/留出段也有变化：AAPL约+7.48%/+1.97%，GOOGL约+1.42%/-6.37%，AMZN约+14.40%/-4.72%。这只是相同收盘诊断口径，不是正式留出策略收益。特别是AMZN开发段涨得好，不能据此预期留出段继续上涨。
5. 18个留出交易日较短，不能把Sharpe单一指标当结论，优先并列收益、回撤、持仓/换手与成本，并如实解释样本局限。

## 当前建议与边界

暂时保留日期：2024用于论文时期复现，2026用于另一市场环境下的受控比较。应在方案中明确“跨环境验证”，不再暗示两个窗口行情相似。若主要目标改为相似行情的复现，应事先制定窗口长度、波动、趋势和数据覆盖标准再选样，记录全部候选；不按更容易盈利或Agent回测成绩挑区间。

本次查看了留出期的历史价格统计，必须保留这一事实：后续可以称“预留给Agent评测的历史区间”，不能称研究者从未查看过的盲测市场。当前没有运行留出期Agent，也不因本次涨跌诊断更改日期、参数或策略规则。是否改实验范围由周晓杨决定，本次未替换proposal或执行配置。

## 复现

在项目根目录、包含pandas/numpy/matplotlib的环境运行：

```bash
python reports/market-period-comparison/analyze.py
```

脚本只读取本地团队数据和本目录保存的ETF响应，不联网、不调用LLM。图片period-comparison.png按交易日序号叠加两段总收益路径，起点均为100；两段结束位置不同是窗口长度不同，不是缺失数据。
