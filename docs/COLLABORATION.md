# 团队协作与交接

仓库内的 `TradingAgents项目协作表.xlsx` 是团队交接主文件，包含“主时间线”和“更新日志”。它是随Git版本管理的文件，不是在线自动同步表。

每次工作完成后：

1. 先同步分支最新版本，避免多人同时覆盖同一工作表。
2. 更新主时间线中对应任务的状态、交付物、下一位负责人和验收要求。
3. 在更新日志追加一行：日期、本人、任务编号、本次改动、验证结果、代码或证据路径、未完成事项、接手人、下一步和期限。保留历史记录，不覆盖他人日志。
4. 将工作表和实际代码/文档一并提交。代码已写、测试通过、数据已验收、课程平台已提交是不同状态，分别记录。

A Zhou Runyu负责Agent工程；B Li Ziqi负责数据与回测；C Zhao Tianyu负责实验与成本；D Zhou Xiaoyang负责方案、统筹、分析和报告整合。具体任务与依赖以工作表为准。

当前最新方案见根目录proposal.md，实施约束见protocol.md。正式窗口、新闻源及成本规模仍需验收和冻结；当前两分析师配置及Notebook演示日期不代表正式四分析师实验已完成。

API密钥仅放本地环境变量或被忽略的.env。原始数据通过Release分发；工作表记录数据版本、路径和验收结果，不写入密钥。
